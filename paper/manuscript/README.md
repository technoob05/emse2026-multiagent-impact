# EMSE submission source

This flat directory follows the Springer Nature sn-jnl Version 3.1 (December
2024) submission layout and uses author-year sn-basic references.

Build the manuscript locally with:

    pdflatex -interaction=nonstopmode -halt-on-error main.tex
    bibtex main
    pdflatex -interaction=nonstopmode -halt-on-error main.tex
    pdflatex -interaction=nonstopmode -halt-on-error main.tex
    pdflatex -interaction=nonstopmode -halt-on-error main.tex

Build the separate technical appendix with the same sequence:

    pdflatex -interaction=nonstopmode -halt-on-error technical_appendix.tex
    bibtex technical_appendix
    pdflatex -interaction=nonstopmode -halt-on-error technical_appendix.tex
    pdflatex -interaction=nonstopmode -halt-on-error technical_appendix.tex
    pdflatex -interaction=nonstopmode -halt-on-error technical_appendix.tex

The project-level reproducible build runs the analyses, generates
`generated_appendix_tables.tex`, compiles both documents, scans both logs, and
prepares an archival source bundle plus a portal-facing manuscript source ZIP,
manuscript PDF, and `ESM_1.pdf`:

    powershell -ExecutionPolicy Bypass -File ..\..\scripts\build_submission.ps1

Clean auxiliary files with:

    latexmk -C main.tex
    latexmk -C technical_appendix.tex

Before submission, replace every `Pending` value, confirm the declarations and
AI-use disclosure, add the public artifact archive, rerun the literature update
and all analyses, and inspect both PDFs. Complete the frozen semantic gate only
if semantic-overlap claims are added. The archival source bundle contains both
LaTeX documents and the generated appendix tables. The portal staging folder
contains only the source needed for `main.tex`; upload `ESM_1.pdf` separately as
Online Resource 1. Third-party raw datasets are intentionally excluded from all
submission bundles. `Fig1.pdf`, `Fig2.pdf`, and `Fig3.pdf` are generated by the
coordination-topology visualization script. `FigS1.pdf` and `FigS2.pdf` are
generated by the dataset visualization script for Online Resource 1.
The untouched official vendor package is retained in ../template/ but should
not be uploaded with the manuscript.
