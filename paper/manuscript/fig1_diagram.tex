% Figure 1, drawn in TikZ.
%
% Every actor, clock reading and discarded event below is a macro defined in
% fig1_values.tex, which scripts/figures/generate_figure1_macros.py writes from
% outputs/worked_example/. Nothing here is an illustration and nothing here is
% a literal number: change the worked example and this diagram follows it.
%
% Geometry. The canvas is 130 mm wide, a hair under the 372 pt text width, so
% the picture never overfills \linewidth. Cards sit on one shared four-column
% grid (width 27 mm, gutter 22/3 mm) that Panel A's chain and Panel B's ladder
% both use, so the two panels line up column for column. Corner radius is 2 mm
% on every card, stroke weight 0.4 pt on every card border, and arrows are
% shortened by 0.6 mm at each end so they start and stop on a node border
% rather than crossing it.
%
% Height matters as much as width. The picture is 138.5 mm tall; with the
% caption that is just inside what sn-jnl will place at the top of a text page,
% and a few millimetres more sends the float off to a page of its own several
% pages after the sentence that refers to it. Keep it under 140 mm.
%
% Colour. The icons carry the palette, so the accents follow them rather than
% competing: purple for the product that wrote the change, blue for the product
% that reviewed it, green for the person, orange for the merge, and the same
% four hues run up the ladder. Every piece of text is a dark ink on white or on
% a very light tint of its own hue, so nothing falls below 4.5:1.
