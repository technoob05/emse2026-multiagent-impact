% Figure 1, drawn in TikZ.
%
% This is a schematic of the measurement design, not a worked example. Nothing
% in it is a reading taken from one pull request: the cards name roles, the
% axis is ordinal rather than linear in hours, and every clause states the
% general rule rather than the instance that happens to illustrate it. The
% products are named only parenthetically, as examples of the role.
%
% ---------------------------------------------------------------------------
% GRID. The canvas is 130 mm wide, a hair under the text width, so the picture
% never overfills \linewidth. Each panel is a rounded container spanning the
% full width, and the cards sit inside it on a four-column grid with a 3.5 mm
% side margin: column width 25.5 mm, gutter 7 mm, so the left edges are 3.5,
% 36, 68.5, 101 and the centres are 16.25, 48.75, 81.25, 113.75. Those eight
% numbers are the only horizontal coordinates a card may use, and the 7 mm
% gutter is what makes room for a short-shafted arrow with a broad head.
% Corner radius is 2 mm on every card, 3 mm on the two panel containers,
% stroke weight 0.4 pt on every card border, and the header strip is 5.8 mm on
% all eight cards.
%
% ICONS. Never sized by height alone: the set mixes tall glyphs (robots) with
% wide ones (speech bubbles), and matching one dimension makes the other look
% wrong. \FigOneIcon fits a glyph inside a uniform box with keepaspectratio and
% then raises it so its optical centre sits on the baseline. A composition is
% therefore one \hbox whose width is the true ink width and whose baseline is
% the shared centre line, so \node[anchor=center] centres the group itself
% rather than centring a pair of unequal boxes and leaving the ink off-centre.
%
% HEIGHT. The float slack on this figure's page is almost exactly the height of
% the picture, so a few millimetres more sends it several pages past the
% sentence that refers to it. The ceiling is 135.8 mm. This version is
% 134.5 mm, up from 131.0: the calendar wanted 7.5 mm of clear air above the
% t_merge label and the green claim line was 1 mm away, so the whole timeline
% block and Panel B moved down 3.5 mm together, which keeps the gap between the
% two halves at 2.6 mm. That spends nearly all the remaining slack. 1.3 mm is
% left. Nothing else may grow, and \ref{fig:contract} must still read page 11.
%
% ARROWS. Panel A's three chain arrows are one arrow drawn three times: same
% slate, same 1.5 pt weight, same Triangle head. The chain is a chain, and a
% second colour inside it would read as an inconsistency before it read as
% emphasis; the claim about the step through the person is carried by the green
% sentence set under that step, which is where the emphasis belongs. Panel B's
% three arrows share that geometry and each takes the HUE of the rung it points
% into -- blue, green, orange -- so the three of them step along the ramp with
% the eye and none of them is slate. They are not the rung's exact fill: rung 2's
% own strip measures 2.98 to 1 against the page, rung 3's 2.62 and rung 4's 2.34,
% so an arrow painted in the strip colour would be a pale smear rather than a
% stroke. Each arrow sits 14 L* below its rung at the same hue and the same
% chroma, which is the smallest offset that clears 3 to 1 on the weakest of the
% three: measured against white the shafts read 4.83, 4.21 and 3.70. Hue still
% names the target and the three still lighten in the ramp's own order; what was
% given up is the byte-exact match to the strip, and it was given up on purpose.
% The time axis is heavier still, 1.6 pt, because it is a spine rather
% than a link. Heads are as wide as
% they are long and the shafts are short, so an arrow reads as a push rather
% than as a needle. The small arrows inside the rung cards are left alone.
%
% COLOUR. Panel A is categorical and the icons carry the palette: purple for the
% product that writes the change, blue for the product that reviews it, green for
% the person, orange for the merge, brick for what the rules exclude. Panel B is
% ORDINAL and now runs on a RAINBOW, sampled from the gradient arrow that serves
% as its legend. A rainbow is the standard wrong answer for ordinal data, because
% the usual rainbow is not monotone in lightness and so leaves hue as the only
% carrier of order, which greyscale and colour-blind readers cannot recover. This
% particular gradient escapes the worst of that: its lightness rises along its
% length, monotonically, from the indigo tail to the orange head. It escapes it
% only partly, though, and the partial part is written down here rather than
% smoothed over.
%
% As sampled, the four stops are monotone in greyscale but grossly uneven: 102,
% 108, 158 and 170 out of 255, steps of 6, 49 and 12. Rungs 1 and 2 would be
% twins on a monochrome printer and so would rungs 3 and 4; the ladder would read
% as two pairs, not four rungs. The 4.5-to-1 rule then forced the tail up (see
% the ramp definition), and lifting the two stops that could not carry type is
% what re-spaces the ladder: the printed rungs measure 139, 149, 160 and 170,
% steps of 10, 10 and 10, strictly increasing. Ten levels is a real step but it
% is thin: the previous teal-to-violet ramp had 27. A greyscale reader can still
% put the four in order, but must look, where before it was immediate.
%
% Order is therefore carried three times over and colour is the weakest of the
% three: by the NUMERALS 1 to 4 in the strips, by LEFT-TO-RIGHT position, and by
% the ramp. Colour here is redundant encoding, not the only encoding, which is
% why a rainbow is affordable at all. What a greyscale reader loses is the
% at-a-glance read of relative strength -- whether rung 3 is much stronger than
% rung 2 or only a little -- not the order itself.
%
% The ramp runs LIGHT because ink, not white, sets the type. 4.5 to 1 against ink
% needs L* at or above 57, so the darkest rung is held at 58.0 and the ramp is
% built upward from there. There is no crossover: one ink, all four rungs, and
% the pill's two words in the same ink on the page. A scale that started
% dark-on-light and finished light-on-dark would read as a mistake before it read
% as a scale.
% Sampled from the 400 dpi render of the typeset page: white on Panel A's four
% strips measures 9.02, 6.29, 6.14 and 5.84 to 1; INK on the four ramp strips
% 4.66, 5.30, 6.02 and 6.76; ink on every tint better than 13.4, slate on the
% tints better than 7.2, ink on white 15.9 for the pill's two words, green on
% white 6.14, brick on white 6.42. The worst reading in the figure is 4.66 to 1,
% ink on rung 1, which is now the binding constraint.
%
% DIRECTION. The gradient's tail is dark and its head is light, and rung 1 is the
% tail, so this ladder gets LIGHTER as it gets stronger. That is the reverse of
% the usual sequential convention, where more is darker, and it is the reverse of
% the ramp this figure used before. It is not an accident: the pill is the source
% image and the rungs are read off it left to right, so the direction is the
% gradient's, not a choice made here. The numerals and the left-to-right order
% are what keep it unambiguous.
%
% The strip-to-tint break inside each rung is 38, 34, 29 and 24 L*, wide the
% whole way along; the old ramp's rung 1 had only 6 and had to lean on chroma.
% That problem is gone, and the card borders improved with it: drawn in the strip
% colour, they now read 3.39, 2.98, 2.62 and 2.34 to 1 against the page where the
% old ramp's read 1.30, 1.71, 2.30 and 3.18, so the weakest card outline in
% Panel B went from 1.30 to 2.34.
%
% TYPE. Lato, asked for by family so the article's own type is untouched.
% Three sizes only: 9 pt bold for panel titles and card names, 8 pt for body
% prose and axis labels, 7 pt for the card qualifiers and the exclusion note.
% Nothing smaller.
