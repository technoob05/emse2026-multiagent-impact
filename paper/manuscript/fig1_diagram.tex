% Figure 1, drawn in TikZ.
%
% This is a schematic of the measurement design, not a worked example. Nothing
% in it is a reading taken from one pull request: the cards name roles, the
% axis is ordinal rather than linear in hours, and every clause states the
% general rule rather than the instance that happens to illustrate it. The
% products are named only parenthetically, as examples of the role.
%
% ---------------------------------------------------------------------------
% GRID. The canvas is 130 mm wide, a hair under the text width, so the picture
% never overfills \linewidth. Each panel is a rounded container spanning the
% full width, and the cards sit inside it on a four-column grid with a 3.5 mm
% side margin: column width 25.5 mm, gutter 7 mm, so the left edges are 3.5,
% 36, 68.5, 101 and the centres are 16.25, 48.75, 81.25, 113.75. Those eight
% numbers are the only horizontal coordinates a card may use, and the 7 mm
% gutter is what makes room for a short-shafted arrow with a broad head.
% Corner radius is 2 mm on every card, 3 mm on the two panel containers,
% stroke weight 0.4 pt on every card border, and the header strip is 5.8 mm on
% all eight cards.
%
% ICONS. Never sized by height alone: the set mixes tall glyphs (robots) with
% wide ones (speech bubbles), and matching one dimension makes the other look
% wrong. \FigOneIcon fits a glyph inside a uniform box with keepaspectratio and
% then raises it so its optical centre sits on the baseline. A composition is
% therefore one \hbox whose width is the true ink width and whose baseline is
% the shared centre line, so \node[anchor=center] centres the group itself
% rather than centring a pair of unequal boxes and leaving the ink off-centre.
%
% HEIGHT. The float slack on this figure's page is almost exactly the height of
% the picture, so a few millimetres more sends it several pages past the
% sentence that refers to it. The ceiling is 135.8 mm. This version is
% 134.5 mm, up from 131.0: the calendar wanted 7.5 mm of clear air above the
% t_merge label and the green claim line was 1 mm away, so the whole timeline
% block and Panel B moved down 3.5 mm together, which keeps the gap between the
% two halves at 2.6 mm. That spends nearly all the remaining slack. 1.3 mm is
% left. Nothing else may grow, and \ref{fig:contract} must still read page 11.
%
% ARROWS. Panel A's three chain arrows are one arrow drawn three times: same
% slate, same 1.5 pt weight, same Triangle head. The chain is a chain, and a
% second colour inside it would read as an inconsistency before it read as
% emphasis; the claim about the step through the person is carried by the green
% sentence set under that step, which is where the emphasis belongs. Panel B's
% three arrows share that geometry but each takes the fill of the rung it points
% into, so the arrows climb the ramp with the eye. The time axis is heavier
% still, 1.6 pt, because it is a spine rather than a link. Heads are as wide as
% they are long and the shafts are short, so an arrow reads as a push rather
% than as a needle. The small arrows inside the rung cards are left alone.
%
% COLOUR. Panel A is categorical and the icons carry the palette: purple for the
% product that writes the change, blue for the product that reviews it, green for
% the person, orange for the merge, brick for what the rules exclude. Panel B is
% ORDINAL, so it may not borrow those four hues -- purple would mean "wrote the
% change" on one half of the page and "rung 1" on the other, and four categorical
% hues would say "four kinds" where the figure means "four strengths". The rungs
% therefore run on one desaturated blue-grey ramp, light at rung 1 and dark at
% rung 4, at a saturation no Panel A accent comes near, so it reads as structure
% rather than as a fifth category. The WEAKER-to-STRONGER pill is filled with the
% dark end of that same ramp and sits at the strong end of the ladder.
% Sampled from the 400 dpi render of the typeset page: white on Panel A's four
% strips measures 9.02, 6.29, 6.14 and 5.84 to 1, white on the four ramp strips
% 5.94, 7.98, 10.74 and 14.44, ink on every tint better than 11.7, slate on the
% tints better than 6.3, green on white 6.14, brick on white 6.30. The worst
% reading in the figure is 5.84 to 1, white on Panel A's orange strip.
%
% TYPE. Lato, asked for by family so the article's own type is untouched.
% Three sizes only: 9 pt bold for panel titles and card names, 8 pt for body
% prose and axis labels, 7 pt for the card qualifiers and the exclusion note.
% Nothing smaller.

% ----------------------------------------------------------- card machinery
% One card: #1 left edge, #2 top, #3 bottom, #4 accent, #5 body tint, #6 the
% name reversed out of the header strip. The strip is filled inside a clip of
% the card's own rounded outline, so its top corners take the card's 2 mm
% radius and its bottom edge is square: one shape, no seams, and no second set
% of coordinates to keep in step with the first.
\newcommand{\FigOneStrip}{5.8}
\newcommand{\FigOneWid}{25.5}
\newcommand{\FigOneCard}[6]{%
  \begin{scope}
    \clip[rounded corners=2mm] (#1,#2) rectangle (#1+\FigOneWid,#3);
    \fill[#5] (#1,#2) rectangle (#1+\FigOneWid,#3);
    \fill[#4] (#1,#2) rectangle (#1+\FigOneWid,#2-\FigOneStrip);
  \end{scope}
  \draw[card, draw=#4] (#1,#2) rectangle (#1+\FigOneWid,#3);
  \node[anchor=center, text=white, font=\FigOneNameFont]
    at (#1+0.5*\FigOneWid,#2-0.5*\FigOneStrip-0.25) {#6};}

% The arrow used inside a card, between two glyphs of a composition. Same
