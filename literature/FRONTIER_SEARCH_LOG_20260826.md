## Decision

Unsafe priority claims include the first AI-to-AI review study, the first
multi-agent review sequence, the first developer-response study, and the first
coordination or handoff study. The defensible contribution is a measurement
combination:

> An event-level public ownership topology after one exact heterogeneous-product
> trigger, separating the addressed edge, rapid fan-out, next owner, and later
> observable state.

## Exact-edge update after the external-data pass

Four additional current-frontier queries were run on 2026-08-26 for exact
reply parents, next public ownership, threaded multi-agent review, and
landmarked PR outcomes. Primary paper and publisher pages were inspected.

New boundary checks were:

- [Agarwal et al., *3100 Opinions on Code Review in an AI World*](https://arxiv.org/abs/2607.07980),
  which builds a practitioner causal theory and shows that coarse repository
  trends can change under different analysis choices;
- [Ogenrwot and Businge, *PatchTrack*](https://link.springer.com/article/10.1007/s10664-026-10869-5),
  which tracks adoption of self-reported ChatGPT-generated patches;
- [Heander et al., *Code review as decision-making*](https://link.springer.com/article/10.1007/s10664-025-10791-2),
  which studies knowledge transfer and shared ownership through human
  think-aloud reviews; and
- [Jin and Chen, *Are LLMs reliable code reviewers?*](https://link.springer.com/article/10.1007/s10515-026-00638-5),
  which tests requirement-conformance judgments rather than public event
  topology.

These works further occupy causal interpretation, patch adoption, human
ownership, and review-quality claims. In this audited search, none reconstructs
the combination used here: an exact heterogeneous-product parent edge, review
de-batching, rapid-burst collapse, the next visible public owner, and a fixed
48-hour/30-day landmark. This remains a scoped contribution claim, not proof
that no unpublished or unindexed work exists.
