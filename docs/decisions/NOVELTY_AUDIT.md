# Novelty audit

## Safe contribution

> We define an observability ladder from agent-brand co-presence to temporal succession, exact-file succession, likely task continuation, and observed coordination. We show that common repository proxies select different populations and change the apparent multi-agent conclusion.

This is a bounded novelty claim, not proof of absolute priority.

## Closest work and remaining gap

- **AIDev** maps the agent-PR ecosystem. Dataset scale is not our novelty.
- **Concurrent cross-agent conflict work** studies overlapping PRs. We study a later PR that starts after the index PR closes and audit whether the trace identifies the same task.
- **Sequential coding-agent benchmarks** use known dependent tasks. We ask whether task dependence can be recovered from public traces.
- **Handoff Debt** studies known takeovers and transferred context in a controlled setting. It owns the handoff-debt concept. We audit whether mined repository proxies can identify a candidate takeover at all.
- **Agent review studies** make review speed or burden a crowded main story. Review remains supporting evidence here.

The residual gap is construct validity: no paper in the current evidence map compares brand, time, path, task, and coordination levels while separating contributor and agent continuity and showing how the substantive result changes.

## Why this is stronger than the old story

The nearest-PR design mixed unrelated repository work. Exact-file succession looked stronger but the pre-audit again found mostly different tasks. Instead of hiding this failure, the paper makes it the result: a plausible mining proxy can turn later PR integration into false ``recovery'' and brand change into false ``handoff.''

## Venue fit

The EMSE special issue asks for mining agent-generated artifacts, human-agent collaboration, multi-agent coordination, failure attribution, and trustworthy practice. A validated measurement framework supports all five areas because each depends on a correct unit of analysis.

## Claims to avoid

- first study of coding-agent handoff;
- true handoff prevalence from the current screen;
- exact-file reuse proves the same task;
- same-task continuation proves intentional transfer;
- agent change caused recovery;
- AI-assisted screening is human ground truth;
- agent diversity proves coordination.

## Go/no-go

Proceed with the measurement-validity paper after dual human coding and held-out validation. If validated changed-agent cases remain small, keep RQ3 descriptive and do not estimate an agent effect.
